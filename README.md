# Multivendor Network CLI Tools

Two zero-dependency single-file HTML tools for network engineers:

- **[Configurator](https://gesh75.github.io/multivendor-cli-configurator/)** (index.html) — GUI form → live CLI for Cisco / Juniper / Arista, all roles (router/switch/firewall).
- **[Cheatsheet](https://gesh75.github.io/multivendor-cli-configurator/cheatsheet.html)** (cheatsheet.html) — 187 searchable commands across IOS / IOS-XE / NX-OS / ASA / Junos / EOS.

Open in any modern browser. No build, no install.
